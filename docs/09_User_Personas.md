# User Personas

## Super Administrator

Responsibilities

- Manage organizations
- Manage subscriptions
- Monitor system health
- Configure platform settings

Permissions

- Full system access

---

## Organization Administrator

Responsibilities

- Manage employees
- Configure departments

Permissions

- Organization-wide access

- HR module access
